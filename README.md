# pairwise-aoe-los

手雷在墙后爆炸，墙另一侧的角色掉了半管血，站在掩体后的坦克却没事：范围伤害只按球形距离判定，没有从爆心到目标做视线遮挡；多层建筑只查一层碰撞，楼上被楼下爆炸波及；伤害衰减按直线距离，掩体边缘和开阔地一样；友军和敌人共用一套伤害表，误伤规则失效；爆炸点被物体挡住时，伤害中心没有回退到最近可见点；服务器和客户端各自算爆炸位置，延迟下判定不一致；AOE 网格查询只查一次，动态物体后进入范围不受伤；多个爆炸叠加时没有伤害上限，瞬间秒杀；视线检测只打一条射线，角色边缘露出就全额伤害；爆炸对可破坏物体和角色的伤害系数没分开；范围查询的格子边界重复计数，边缘目标吃两次伤害；延迟补偿把目标倒带到过去，掩体状态却用当前帧；伤害事件没有幂等键，重试导致重复扣血。gameplay/aoe_los.py 是核心，tests/test_aoe_los.py 15个红。要修的是：视线遮挡；多层查询；掩体衰减；阵营规则；爆心回退；服务器权威；动态查询；叠加上限；多射线采样；材质系数；格子去重；延迟一致；事件幂等。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
